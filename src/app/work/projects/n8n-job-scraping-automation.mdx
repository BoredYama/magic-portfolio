## Overview

I developed automated job-scraping workflows in **n8n** that do the searching and first-pass filtering for me, and deliver only the relevant leads.

## How it works

The Reddit workflow runs on a schedule in n8n:

1. **Collect:** a schedule trigger fetches new posts from job subreddits over HTTP, and a code step filters and cleans them.
2. **Skip duplicates:** each post is checked against **PostgreSQL**, so leads that were already sent are never repeated.
3. **Ask the LLM:** posts are looped through an LLM chain using **Gemini**, which judges whether each one is a genuine, relevant opportunity and writes a one-line verdict. A parser turns its answer into structured data, and a short wait keeps the calls within rate limits.
4. **Quality gate:** only posts that pass the AI quality filter continue.
5. **Deliver:** passing leads are posted to **Discord** with the post details, the verdict and a link. The database is then updated so the post is marked as seen.

## The result

Leads arrive in a Discord channel, each with the subreddit, upvotes, an excerpt and the AI's one-line reason for passing it through.

## Stack

- n8n for workflow orchestration
- Gemini for LLM-based filtering
- PostgreSQL to track posts already seen
- Discord for delivery
- Runs on my self-hosted Oracle Cloud infrastructure
