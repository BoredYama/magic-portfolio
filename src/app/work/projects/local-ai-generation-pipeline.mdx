## Overview

I built and maintain a local AI generation pipeline on my own Linux workstation with an NVIDIA GPU. Everything runs on my own hardware, so I can iterate on video and music generation without relying on hosted services.

## What I built

- **ComfyUI** as the node-based core of the pipeline for building and running generation workflows.
- **LTX video** for AI video generation.
- **ACE-Step** for AI music generation.

## Keeping it running

- Debugged custom ComfyUI nodes when updates or dependencies broke workflows.
- Managed Python environments so the different models and node packs could run side by side.
- Set up and maintained the Linux/NVIDIA workstation the pipeline runs on.

## Why it matters

My background in 3D texturing and quality analysis means I look at generated output the same way I reviewed production assets: against a reference, frame by frame, with an eye for artifacts.
