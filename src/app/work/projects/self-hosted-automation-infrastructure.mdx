## Overview

I manage self-hosted infrastructure on an **Oracle Cloud** virtual machine. It runs the services behind my automation workflows, including the n8n job-scraping automation.

## Architecture

The diagram above shows the setup. n8n and PostgreSQL run as Docker containers on the VM, and systemd keeps them running. n8n pulls from the job sources, calls Gemini for filtering, and posts the results to Discord.

## Responsibilities

- Linux system administration of the VM.
- Running services in **Docker** containers.
- Managing long-running processes with **systemd** so workflows stay up.

## Stack

- Oracle Cloud VM
- Linux
- Docker
- systemd
